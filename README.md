## 📊 Project Overview

An interactive data visualization project analyzing airline passenger satisfaction across multiple Indian airlines from 2012-2018. This Tableau dashboard provides actionable insights into customer satisfaction patterns, flight performance metrics, and passenger demographics.

**Key Focus Areas:**
- Overall passenger satisfaction rates and trends
- Airline performance comparison (Air India, IndiGo, SpiceJet, GoFirst, Air Asia India)
- Flight delay analysis and punctuality metrics
- Customer loyalty and retention patterns
- Class preference and travel behavior analysis

## 🎯 Key Insights

### Overall Satisfaction
- **56.07%** passengers reported neutral/dissatisfied experience
- **43.93%** passengers were satisfied
- **52.69%** neutral/dissatisfied with in-flight service specifically

### Airline Performance
- **Air India**: Highest passenger count (25.20%), 2,160 repeat bookings
- **SpiceJet**: Second highest market share (24.83%), 2,059 repeat bookings  
- **IndiGo**: Lowest departure delays (7.70 min average to Belgium)
- **SpiceJet**: Highest delays (23.89 min average)

### Passenger Demographics
- Business class preferred by majority of frequent flyers
- 65-1,386 passengers analyzed across different travel classes
- Gender-based rating patterns across flight distances

## 🚀 How to Use

### Viewing the Dashboards
1. **PDF Format**: Open `Data_Visualization_Project.pdf` for static dashboard views
2. **Tableau Workbook**: Download the `.twb` file and open in Tableau Desktop/Reader
3. **Interactive Features**: Use filters to explore data by airline, gender, destination, and time period

### Key Interactive Elements
- **Destination Country Filter**: Analyze performance by route
- **Gender Selection**: Compare male vs female satisfaction patterns  
- **Flight Name Filter**: Focus on specific airlines
- **Class Filter**: Examine Business/Economy/Economy Plus preferences
- **Year Range**: Track temporal trends from 2012-2018

## 📊 Key Metrics Tracked

| Metric | Description |
|--------|-------------|
| Overall Satisfaction | Customer satisfaction rating (satisfied/neutral/dissatisfied) |
| Departure Delay | Average delay in minutes by airline and destination |
| Repeat Bookings | Number of times passengers chose the same airline |
| Overall Ratings | Customer ratings on 1-5 scale |
| Flight Distance | Distance traveled vs satisfaction correlation |
| Class Distribution | Business/Economy/Economy Plus passenger breakdown |

## 💡 Business Recommendations

Based on the analysis, key recommendations include:

1. **Improve In-Flight Service**: 52.69% dissatisfaction indicates need for service enhancement
2. **Reduce Delays**: SpiceJet should prioritize punctuality improvements  
3. **Maintain Quality**: IndiGo's low delay times contribute to customer satisfaction
4. **Target Business Travelers**: High repeat booking rates indicate loyalty potential
5. **Gender-Specific Services**: Ratings vary by gender on long-distance flights
