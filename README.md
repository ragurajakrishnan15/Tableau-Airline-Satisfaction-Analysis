# ✈️ Airline Passenger Satisfaction Analysis

This project analyzes airline passenger satisfaction to identify key factors that influence customer experience and overall satisfaction levels. The insights from this analysis can help airlines improve service quality, customer retention, and operational decision-making.

---

## 📌 Project Overview

The goal of this project is to:
- Understand passenger satisfaction trends
- Identify factors that contribute to satisfied vs. dissatisfied customers
- Visualize patterns using interactive dashboards
- Provide actionable insights for airline service improvement

---

## 📊 Dataset Description

The dataset contains passenger information including:
- Demographics (age, gender, travel type)
- Flight details (class, distance, delays)
- Service ratings (seat comfort, inflight service, cleanliness, food, etc.)
- Overall satisfaction label (Satisfied / Neutral / Dissatisfied)

---

## 🛠️ Tools & Technologies Used

- **Tableau** – Interactive dashboards and visual analytics  
- **Data Cleaning & Preprocessing** – Handling missing values and normalization  
- **Exploratory Data Analysis (EDA)** – Trend and pattern discovery  

---

## 📈 Key Insights

- Business class passengers report significantly higher satisfaction levels
- Inflight service, seat comfort, and on-time performance are strong satisfaction drivers
- Long delays have a clear negative impact on customer experience
- First-time customers tend to be less satisfied than returning customers

---

## 📂 Project Files
